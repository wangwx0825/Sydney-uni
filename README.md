# Sydney-uni capstone
# 面向大模型失败感知的答案可靠性评估项目

## 项目概述

本项目围绕**大模型失败感知（Failure-Aware LLM）**展开，核心目标是让大语言模型在生成答案的同时，对答案的**可靠性 / 自信度**进行评估。

如果模型判断当前答案的可靠程度较低，则选择**拒答**；如果模型认为答案足够可靠，则正常输出答案。

该项目主要关注一个常见问题：  
大语言模型经常会生成看起来流畅、合理，但实际上错误的回答，并且有时还会表现出较高的“自信”。因此，本项目希望探索一种更有效的机制，使模型输出的 confidence 能够更接近真实正确率，从而支持更安全、更可信的回答策略。

---

## 研究目标

本项目的核心研究问题是：

> 能否为大语言模型设计一种实用的可靠性评估机制，使模型给出的 confidence 更真实地反映答案正确率，并进一步支持“回答 / 拒答”的决策？

具体来说，本项目主要希望解决以下问题：

- 分析模型 confidence 与真实 accuracy 之间的关系
- 验证模型**自报 confidence** 是否可信
- 比较不同任务类型下 confidence 机制的表现差异
- 尽可能找到一组参数或方法，使 confidence-accuracy 关系更接近理想状态
- 基于可靠性分数，为模型设计一个简单的拒答机制

---

## 已完成的工作

截至目前，本项目已经完成了以下几个方面的工作：

### 1. 开源模型的本地部署
选择了一个开源大语言模型，并完成本地部署，作为后续实验的基础模型。

### 2. 数学类数据集上的初步测试
项目第一阶段主要使用**数学类问答数据集**对模型进行测试，目的是先观察模型的基础推理能力，并分析模型输出答案时的 confidence 与真实 accuracy 的关系。

### 3. 模型自报 confidence 的实验
在生成答案的同时，让模型额外输出一个 confidence 分数，用于表示它对当前答案的自信程度。

初步实验结果表明：

- 模型经常给出较高 confidence
- 但实际正确率并不高

这说明模型的自报 confidence 存在明显失配问题，不能直接视为可靠的可信度指标。

### 4. 参数与配置的持续调试
针对上述问题，项目进一步对不同的参数类型、参数值以及相关配置进行了多轮调试，希望改善 confidence 与 accuracy 之间的对应关系。

项目的目标不是单纯让 confidence 数值变高，而是尽量让：

> confidence ≈ 实际答案正确率

### 5. 迁移到文字类数据集进行测试
在数学类任务上取得一定改进后，项目进一步将实验迁移到**文字类 / 事实类 / 语言理解类数据集**上进行测试。

实验发现：

- 在数学类任务上效果较好的参数组合
- 在文字类任务上往往表现较差

这说明，大模型的可靠性估计可能具有较强的任务依赖性，不同类型的问题可能需要不同的 confidence 机制或参数策略。

---

## 当前阶段的主要发现

根据目前的实验结果，可以得到以下初步结论：

1. **模型自报 confidence 并不天然可信**  
   模型可能在答案错误的情况下依然给出较高自信度。

2. **confidence 机制具有明显的任务依赖性**  
   在数学类任务上表现较好的参数设置，并不一定适用于文字类任务。

3. **比起单纯提高 confidence，更重要的是提高 confidence 与 accuracy 的一致性**  
   只有当高 confidence 对应高正确率时，这个 confidence 才真正有意义。

4. **单一参数组合可能难以适配所有任务**  
   不同任务场景可能需要不同的估计方法，或采用复合型特征来评估可靠性。

## 方法流程

当前项目的整体实验流程如下：

1. 选择并本地部署开源大模型  
2. 在指定数据集上运行模型推理  
3. 收集以下信息：
   - 模型答案
   - 模型输出的 confidence
   - 标准答案
   - 答案是否正确
4. 比较 confidence 与真实 accuracy 的对应关系  
5. 调整参数与相关配置  
6. 在不同数据集上重复实验  
7. 分析 confidence-accuracy 校准效果是否得到改善

本项目关注的理想目标是：

- 高 confidence 的答案，真实正确率也应较高
- 低 confidence 的答案，应尽量被拒答或过滤
- confidence-accuracy 曲线尽可能接近理想校准关系

---

## 项目意义

在许多实际应用场景中，一个“错误但自信”的回答，往往比“选择不回答”更危险。  
因此，让模型具备一定的失败感知能力和拒答能力，对于提升大模型系统的安全性、可靠性和可信度具有重要意义。

本项目涉及和对应的方向包括：

- 可信人工智能（Trustworthy AI）
- 不确定性估计（Uncertainty Estimation）
- 置信度校准（Calibration）
- 选择性预测（Selective Prediction）
- 拒答 / 拒绝机制（Abstention / Refusal）

---

## 当前局限

目前项目仍处于探索和迭代阶段，主要局限包括：

- confidence 估计机制在不同任务上的泛化能力仍然有限
- 实验结果对参数选择较为敏感
- 当前方法还需要更系统的评估指标支持
- 更稳定、更通用的可靠性评估机制仍在继续研究中
